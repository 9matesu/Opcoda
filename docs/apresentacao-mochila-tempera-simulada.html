09 Critério de Aceitação Rafael Elisei

Por que aceitar uma solução pior?

CRITÉRIO DE METROPOLIS
P = e^( Δ / T )
EXEMPLO PRÁTICO:
Solução atual = 100  →  Nova solução = 90
É pior (Δ = -10).
Temperatura alta (início):  Ainda pode aceitar a solução pior para explorar novas combinações.
Temperatura baixa (fim):  Provavelmente rejeita a solução pior, tornando a busca estritamente seletiva.

A2 Slide Reserva · Pseudocódigo Backup

Pseudocódigo completo do algoritmo

GERAR solução inicial viável S (peso ≤ C)
AVALIAR solução inicial: V(S)
T = T₀
ENQUANTO T > Tmin:
    GERAR vizinha S' por mutação (bit flip)
    SE S' viável (peso ≤ C):
        Δ = V(S') − V(S)
        SE Δ > 0: S = S'   // aceita melhoria
        SENÃO SE random(0, 1) < exp(Δ / T): S = S'   // aceita piora
    REDUZIR temperatura: T = α · T
RETORNAR melhor solução encontrada
